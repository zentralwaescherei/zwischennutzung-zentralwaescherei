# Fonts

`monument-grotesk-regular.woff2`, `monument-grotesk-heavy.woff2` and
`monument-grotesk-mono-regular.woff2` are **OFL placeholders** until the
Monument Grotesk license is in place:

- `monument-grotesk-regular.woff2` — Inter Regular (OFL, rsms/inter)
- `monument-grotesk-heavy.woff2` — Inter Black (OFL, rsms/inter)
- `monument-grotesk-mono-regular.woff2` — JetBrains Mono Regular (OFL, JetBrains)

Swap in the licensed Monument Grotesk WOFF2 files under these exact filenames
and nothing else in the code needs to change.
